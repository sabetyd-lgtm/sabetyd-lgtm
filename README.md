### Featured project

**[Monthly Reporting Pipeline — Park Place Car Wash](https://github.com/sabetyd-lgtm/pos-reporting-pipeline)**

Park Place Car Wash in Encinitas, San Diego, tracked its monthly numbers by
hand — pulling figures out of the point-of-sale system and typing them into a
spreadsheet, which took hours and let errors creep in. I built a system that
does it automatically on the 1st of every month:

- Pulls the month's sales from the Clover point-of-sale system
- Counts each category using the business's own rules, which I worked out from
  years of existing figures and documented for the staff
- Writes the results into the owner's existing Google Sheet, matching its format
- Re-checks its own work and sends an alert if anything is off

Running unattended since September 2026. Its self-check has already caught and
helped fix a real data problem.
